# Clipboard Landing Page - Frontend Mentor Challenge

- This is my solution to the **Clipboard Landing Page** challenge from Frontend Mentor.
- The project is built using **HTML and CSS**, with a focus on Flexbox, responsive design, section layouts, download buttons, feature sections, and adapting the design across desktop, tablet, and mobile breakpoints.

## Challenges Faced

- Creating the different sections of the landing page while keeping the layout consistent
- Aligning the computer image and feature content correctly on desktop screens
- Creating responsive layouts for tablet and mobile screens
- Adjusting the feature sections from horizontal layouts to vertical layouts
- Making the company logos responsive across different screen sizes
- Creating a responsive footer with navigation links and social media icons
- Finding the right combination of Flexbox, Grid, widths, gaps, and media queries
- Maintaining consistent spacing between different sections of the page
